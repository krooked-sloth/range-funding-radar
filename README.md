# Range Funding Radar

[Range Funding Radar](https://krooked-sloth.github.io/range-funding-radar/docs/) is a source-linked directory of U.S. shooting-range grant programs, application windows, matching requirements, and project rules.

It is built for public-range operators, nonprofit clubs, local governments, advisers, and project teams that need one place to see what is open and what is coming next.

## What is included

- Official program and application links
- Current or next known application window
- Published funding and match information
- A short note about mapping, project-visual, or range-safety requirements
- A verification date for every record

The directory does not determine eligibility, provide grant advice, or replace the issuing agency's current instructions. Always confirm requirements with the program before spending money or submitting an application.

## Use the data

The full dataset is in [`data/programs.json`](data/programs.json). Each record uses the same small schema so it can be reused in a spreadsheet, website, or internal grant calendar.

## Submit a correction

If an official deadline, funding amount, or program link changed, [open a correction request](https://github.com/krooked-sloth/range-funding-radar/issues/new?template=program-update.yml). Include an official source. Commercial links and unsourced claims will not be added.

## Maintained by

This project is maintained by [Range Operations](https://rangeoperations.com), an outdoor safety-fan, Surface Danger Zone, projectile-containment, and shotfall mapping practice within [Falconer Operations Group](https://falconeroperations.com).

[Range Master](https://apps.apple.com/us/app/range-master-danger-zone/id6785127377) is the companion first-pass planning app for iPhone and iPad. It is not open source, and this repository does not contain the app, ballistic models, safety-engine code, customer data, or final range determinations.
